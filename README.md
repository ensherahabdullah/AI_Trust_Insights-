# AI Trust Insights - Data Preprocessing & Analysis

## Overview

This project explores AI trust and skepticism data using Python. It focuses on understanding the dataset, cleaning missing values, applying preprocessing techniques, and analyzing patterns related to trust in AI-generated responses.

## Dataset

The dataset was obtained from Kaggle:

**Source:** [AI Trust Insights — Kaggle](https://www.kaggle.com/datasets/emanfatima2/ai-trust-insights)

## Tools & Libraries

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Project Workflow

1. **Data Exploration:** Examine the dataset structure, missing values, distributions, and relationships between numerical features.
2. **Data Cleaning:** Handle missing categorical values.
3. **Data Sampling & Summarization:** Select query categories and summarize trust-related patterns.
4. **Feature Scaling & Encoding:** Apply numerical scaling and categorical encoding.
5. **Feature Selection & Dimensionality Reduction:** Explore RFE and PCA.
6. **Data Reshaping:** Use pivot tables, stacking, crosstabs, and value binning to organize and compare data.

## How to Run

1. Download the notebook `AI_Trust_Insights.ipynb`.
2. Download the dataset from the Kaggle source linked above.
3. Open the notebook in Google Colab.
4. Upload `ai_skepticism_dataset.csv` to the Colab session.
5. Run the notebook cells.

## Project Scope

This project demonstrates practical data exploration and preprocessing techniques. It does not focus on training or evaluating a predictive machine learning model.
